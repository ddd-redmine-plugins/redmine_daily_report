# Redmine Daily Report Plugin

![Plugin info at redmine.org](https://img.shields.io/badge/Redmine-plugin-green.svg?)

## 1．Overview of the plugin

This is a plugin for creating daily reports in Redmine. It can create the contents of daily reports to a certain extent automatically based on the records of the working times for the day. It also supports a function that displays the records of working times for a specified period of time on a daily basis.

## 2. Compatibility

The tested version of Redmine is 5.1.

## 3. Installation and uninstallation instructions

Please follow the standard Redmine plugin procedure.

## 5. Dependency

None.

## 6. How to use

The "Daily Report" and "Time Log" will appear in the top right corner. The Daily Report will take you to the screen for creating and viewing daily reports. The Time Log will take you to the screen for viewing daily work time records.
